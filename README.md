# WinterDiary2026

学級向けの「冬休み生活記録」Google Apps Script Webアプリのひな形です。

このリポジトリは公開用です。本番のスプレッドシートID、Apps Script のプロジェクトID、生徒の氏名・パスワード・日記は含みません。

対象期間の初期値は **2026年12月25日〜2027年1月7日（14日間）** です。`設定` シートで変更できます。

`.clasp.json` は clasp でプロジェクトを作ったときに生成されます。スクリプトIDが入るため、Gitには含めません。

## 自分の学級で使うとき

1. このリポジトリを手元に複製し、公開リポジトリへは戻さない運用用の場所で編集します。
2. 画面と `設定` シートの「○年○組」を、自分の学級名に置き換えます。
3. Google スプレッドシートを新しく作り、スクリプトプロパティ `SPREADSHEET_ID` にそのIDを設定します。
4. `Code.gs` の `DEFAULT_SPREADSHEET_ID` は空欄のままにします。本番のIDを書いてコミットしないでください。
5. Webアプリとしてデプロイする前に、先生用パスワード `000000` を変更します。

## ファイル

## 新春おみくじ

生徒は日本時間の2027年1月1日0:00〜1月8日11:59:59に、一人一回おみくじを引けます。期間中の未抽選の生徒にはログイン時に案内し、「あとで引く」も選べます。大吉・中吉・小吉・吉は同じ確率です。結果は初回抽選時に自動作成する「おみくじ」シートへ保存し、期限後も「おみくじ結果」ボタンで閲覧できます。既存の初回セットアップを再実行する必要はありません。

実装は `Omikuji.gs` と `omikuji.html`、独立したデザイン確認用ファイルは `omikuji-preview.html` です。プレビューは公開アプリへ送信しません。

- `requirements.md`: 要件定義書
- `teacher-manual.md`: 先生用マニュアル
- `student-manual.md`: 生徒用マニュアル
- `Code.gs`: Apps Script のサーバー側処理
- `index.html`: Webアプリ本体
- `style.html`: 画面デザイン
- `script.html`: 画面操作
- `appsscript.json`: Apps Script 設定

## 使い方

1. Google スプレッドシートを作成します。
2. Apps Script プロジェクトにこのリポジトリのファイルを配置し、Webアプリとしてデプロイします。
3. スクリプトプロパティ `SPREADSHEET_ID` に、手順1のスプレッドシートIDを設定します。
4. ログイン画面の「初回セットアップ」を押します（初回のみ）。
5. `利用者` シートで、生徒30人分の氏名と6桁パスワードを入力します。
6. `設定` シートで、クラス名と、必要に応じて背景画像URLを入力します。
7. 先生用パスワード `000000` を運用前に変更します。

## 補足

- `DEFAULT_SPREADSHEET_ID` は空欄です。スプレッドシートに紐づけた Apps Script として実行するか、スクリプトプロパティ `SPREADSHEET_ID` を設定してください。
- 「初回セットアップ」は完了後にログイン画面から非表示になり、再実行もできません。

## 背景画像URL

背景画像は Google Drive に保存し、共有設定を行ったうえで `設定` シートの以下の項目にURLを入力します。
Google Drive の通常の共有リンクを貼った場合、アプリ側で表示用URLに変換します。

- `背景_雪景色と青空_URL`
- `背景_こたつとみかん_URL`
- `背景_雪明かりの街_URL`
- `背景_初日の出と富士山_URL`

URLが空欄の場合は、アプリ内の簡易背景が表示されます。画像ファイルはこのひな形には含まれていません。
